## 🛍️ TrendiCart — E-commerce Frontend

### 📌 Overview
A responsive e-commerce frontend showcasing multiple product categories with seamless navigation and clean UI.

### 🛠 Tech Stack
React.js, React Router, CSS3, Vercel

### ✨ Key Features
- 🛒 Product listing, detail pages, and cart UI
- 🔄 Client-side routing with React Router
- 📱 Fully responsive design
- 👕 100+ products across categories

### 🧠 What I Learned
- UI/UX design fundamentals
- State management in React
- Routing without page reloads
